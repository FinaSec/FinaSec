# Francisca Tupkeyi

I’m a cybersecurity student pursuing SOC analyst roles. My portfolio documents how I investigate suspicious network activity, configure Windows security auditing, and verify vulnerability remediation in lab environments.

## Start here

1. [Web01 SOC Investigation](https://github.com/FinaSec/web01-soc-investigation) — I correlated web access logs with Wireshark and Zeek evidence to build an incident timeline and identify what needed further investigation.
2. [Wireshark Malware Traffic Analysis](https://github.com/FinaSec/wireshark-malware-traffic-analysis) — I identified the workstation associated with suspicious traffic using DHCP and NetBIOS evidence, then traced its DNS and HTTP activity.
3. [Cybersecurity Home Lab](https://github.com/FinaSec/Cybersecurity_Home_LAb) — I configured Windows 11 logon auditing and account lockout policies and documented firewall validation in a separate lab.
4. [Metasploitable Vulnerability Assessment](https://github.com/FinaSec/Metasploitable-Vulnerability-Assessment) — I used Nmap and Nessus to assess a lab host, remediated a weak VNC credential, and verified the result with a rescan.

For infrastructure work, see [Proxmox Backup and Recovery](https://github.com/FinaSec/proxmox-backup-and-recovery) and my [IT Infrastructure Portfolio](https://github.com/FinaSec/IT-Infrastructure-Portfolio).
